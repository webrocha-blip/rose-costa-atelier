# Rose Costa Atelier — site demonstrativo

Site estático (HTML/CSS/JS puro), pronto para GitHub Pages.

- `index.html` — página inicial
- `servicos/`, `trabalhos/`, `sobre/`, `contato/` — páginas internas
- `assets/` — estilos e scripts
- `img/` — fotos do Instagram @rose_costacostura

Publicar: crie um repositório, envie estes arquivos para a branch `main` e ative
Settings → Pages → Deploy from branch → `main` / `(root)`.
